# Mostafa Sallam - Java Backend Developer Portfolio

A responsive, high-performance portfolio built with **Next.js**, **React**, and **Tailwind CSS**.

## Overview
This repository contains the source code for my professional portfolio website. It highlights my expertise in Java Backend Development, Domain-Driven Design (DDD), and Reactive Architectures using frameworks like Spring Boot and Quarkus.

## Features
- **Modern Tech Stack**: Built leveraging the power of Next.js static generation.
- **Dynamic Animations**: Enhanced user experience with Lottie animations and Framer Motion.
- **Fully Responsive**: Professionally styled with Tailwind CSS for mobile and desktop screens.
- **Static Hosting**: Configured specifically to be hosted seamlessly via GitHub Pages via the `gh-pages` branch.

## Getting Started

### Local Development
To run this project locally on your machine:

1. **Install dependencies**
```bash
npm install
```

2. **Run the development server**
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Deployment
This site is configured to be exported as raw HTML and pushed to the `gh-pages` branch to bypass traditional CI/CD workflows.

To build and deploy the static site locally:
```bash
npm run build
npm run deploy
```

*(Note: Ensure your GitHub repository settings under "Pages" are set to build from the `gh-pages` branch).*
